# EXPERT-MAP.md

100 expert domains available to consult. Each has a problem to solve, a web angle, and a UI/UX interconnect list. Consult relevant ones before deciding on a task.

## How to consult

Before deciding on any task that touches design, data integrity, or user flow, read this file and pick the experts closest to the problem. You do not need every expert — two or three is usually right. Add more only if the first pass leaves a question unanswered.
